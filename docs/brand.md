# Hamsa — brand & content reference

Collected from the live site (https://www.hamsa.com) as context. **The Figma file is the source of truth for
the new page**; use this for copy, tone, and fallbacks where Figma is silent.

## Company

Hamsa builds financial-market infrastructure: a **Unified Ledger** that uses AI and distributed-ledger tech
for faster, safer, lower-cost clearing and settlement between financial institutions.

- Audience: central banks and Tier-1 financial institutions (e.g. Brazil's DREX pilot)
- Problems solved: interoperability, privacy, speed, without replacing existing systems
- Proof points on the current site: $400B+ in transactions processed, $3.2B in assets tokenized

## Messaging (current site)

- Site title: "Hamsa – Powering the Finternet"
- Headlines: "Bringing Finance In Sync", "Modernizing the Infrastructure of Global Capital Markets", "Trust, Built-In"
- Core modules: Privacy (ZK-based), Automation (smart contracts), Interoperability, Programmability
- Solutions: Subaccounting Platform, Programmable Payments, Asset Tokenization
- Primary CTA: "Build the future with Hamsa" (contact form)
- Nav: Infrastructure, Solutions, Resources (DREX & Beyond), About Us, Newsroom, LinkedIn, X/Twitter
- Tone: professional, forward-looking, technical but accessible; institutional trust
